# オノマトペカーソル / Onomatopoeia Cursor 👀

![キービジュアル](figures/key_visual.png)

**マウスカーソルの動きが、漫画の描き文字になる。** そっと動かせば「ソロソロ」、振り回せば「ブンブン」、急に止めれば「ピタッ!!」——カーソル・クリック・ドラッグ・打鍵・スクロール、あなたの操作の**質**がリアルタイムにオノマトペとして画面に現れるmacOSアプリです。

同時に、これは**「動きを言葉にされると、自分の動作の感覚（自己主体感）はどう変わるか」を問うHCI研究プロジェクト**でもあります。

> 「ソロソロ」と名指しされた瞬間、同じ動きが急にソロソロした動きに感じられる（**変容**）。動いていないのに文字の勢いで動いた気になる（**加速**）。そして「ピタッ!!」と言われると、**言われたからカーソルが止まった気がする**——自分の減速が語を出したのに、語のほうが原因に感じられる因果の逆転（**干渉**）。

## ✨ できること

![語の例示（ストロボカーソル）](figures/teaser_words.png)

- **7つの入力チャネル × 60語形**: カーソル運動（15語）・カーソル下のコンテンツ・キーボード・トラックパッド・クリック・ドラッグ＆ドロップ・ウィンドウの段差、そして**静止**——5秒止まると「すぅすぅ」（寝息）「ウトウト」「ぼー…」がひそやかに浮かび、ときどき「**ビクビクッ**」と飛び起きます
- **語形は動作の質で揺らぐ**: イベントの種類は語の「族」を、動作の質が語の「形」を決めます。同じクリックでも そっと=`ポチ`／きびきび=`カチッ`／叩きつけ=`バチンッ`。日本語音象徴の形態論（濁音=重さ・促音=鋭さ・長音=持続・反復=繰り返し）をそのまま連続パラメータ化しています
- **5言語対応**: 日本語・English・中文・한국어・Français。翻訳ではなく各言語の音象徴の伝統（英=コミックSFX `YEET!`/`KA-BLAMM!!`、中=拟声词 `哐——!!!`、韓=濃音化・母音交替 `따아앙!!!`、仏=BD擬音 `VLAAAN !!`）で再設計
- **漫画品質の描画**: グリフの輪郭が手描き風に沸く「ボイル」アニメーション、1文字ずつの誇張運動、速度系のフラッシュ演出、動きの強さに連動する文字サイズ（0.8〜1.9倍）
- **即応**: 急停止・動き出しはイベント方式で約35〜50msで反応し、その後分類器が精緻化

## 🚀 インストール（3ステップ・ターミナル不要）

1. [Releases](../../releases/latest) から `OnomatopeCursor-x.x.x.zip` をダウンロードして解凍
2. `OnomatopeCursor.app` を **アプリケーション** フォルダにドラッグ＆ドロップ
3. ダブルクリックで起動 → メニューバーに **「オ」** アイコンが出ます

アプリは**Apple公証済み**なのでそのまま開けます。「開いてもよろしいですか？」と確認されたら「開く」を押してください。動作環境: macOS 12以降（Apple Silicon・Intel両対応）。

## 🎛 使い方（メニューバーの「オ」から）

| メニュー | 内容 | 権限 |
|---|---|---|
| 一時停止 / 再開 | 表示を止める（アイコンが薄くなります） | — |
| 背景モード（実験的） | カーソルの下にあるものに反応: テキスト→フムフム／画像→ジロジロ／ボタン→ドキドキ | アクセシビリティ |
| キーボードモード（実験的） | 打鍵速度で ポチポチ→カチャカチャ→カタカタカタ→ダダダダッ、Enterは勢いで たん→**ッッターン！！** | アクセシビリティ |
| トラックパッドモード（実験的） | スクロール=スルスル／ガーッ／シュルシュル／シャッ、修飾キー+スクロール（ズーム）=ガバーッ／キュッ | アクセシビリティ |
| 物理モード | クリック（ポチ〜バチンッ）・ドラッグ（グイグイ／ズルズル）・ドロップ（ポィ！等）・**窓の縁またぎ（カタッ）** | 不要 |

| 言語 / Language | 日本語・English・中文・한국어・Français | — |
| オノマトペ図鑑… | 出した語形のコレクション＋**貢献ポイント**——貯めると**配信パックの新語が解放**される | — |
| 潜在空間HUD（新語を探す）… | 動作をオノマトペθ空間にプロット。**未命名地帯**に入ると内蔵AIがその場で新語を生成 | — |

| 2択クイズ（どっちが自然？） | クリック等の直後にたまに2択が出る——回答が語形マッピングの教師データに（8分に1回まで・6秒で消える） | — |

## 📣 フィードバックの送り方

| 方法 | いつ・なにに |
|---|---|
| **右クリック2連打**（チガウチガウ） | 「この動きにこの語は違う」と思った瞬間に。語・動作特徴量が負例として記録されます |
| 2択クイズに答える | たまに出る「どっちが自然？」——語形マッピングの教師データに |
| メニュー→**アンケートに答える（1分・+5pt）** | 使い心地の定期的なパルス。自由記述も歓迎 |
| メニュー→**フィードバック・リクエストを送る…** | [GitHub Issues](../../issues/new/choose)へ。語ズレ報告・不具合・リクエスト（新しい語/機能/対応アプリ）のテンプレートがあります |
| データ提供に協力（メニュー→研究モード） | 使うだけで匿名の運動-語データが研究に貯まります |

- オーバーレイはクリック透過で操作の邪魔をせず、全スペース・フルスクリーンに追従します
- キーボード/クリック系は**押した事実だけ**を使い、どのキーか・入力内容・クリック先は一切見ません
- アンインストールはアプリをゴミ箱に入れるだけ（ログを残したくない場合は `~/Library/Application Support/OnomatopeCursor/` も削除）

## 🔒 プライバシー

- **「データ提供に協力」OFF（初期状態）ではネットワーク通信は一切ありません**。ONにすると、匿名ID付きで運動特徴量・表示語・フィードバックのみを研究用サーバー（insert-only）に送信します——初回に送信内容を明示して同意を取り、いつでもOFFにできます
- 画面のピクセル・キー入力の内容・クリック先の情報は読み取りません
- アクセシビリティ権限は該当モードをONにした場合のみ使用し、取得するのは「カーソル下のUI要素の種別名」「押鍵の事実」だけです
- 研究ログは明示的オプトイン・ローカル保存のみ・平文JSONL（提出前に自分で中身を確認できます）
- Snyk Code静的解析済み（指摘0件）・テスト41本

## 🔬 研究プロジェクトとして

これは「動きを言葉にされると、自分の動作の感覚（自己主体感）はどう変わるか」を問うHCI研究のプロトタイプでもあります。日本語音象徴の形態論（濁音=重さ・促音=鋭さ・長音=持続・反復）を連続パラメータ化し、オンデバイスの小さなトランスフォーマー（OnomaFormer）が動きの質から新しいオノマトペをその場で生成します。研究の詳細は論文（準備中）で公開予定です。

**「データ提供に協力」で送られる匿名の運動-語データは、この研究の語彙・描き文字の改善に使われます。**

## 🛠 開発

Xcode Command Line Tools（`xcode-select --install`）だけでビルドできます（Xcode不要）:

```bash
git clone https://github.com/ochyai/OnomatopeCursor.git
cd onomatope-cursor
swift run onomatope-tests   # テスト41本（XCTest非依存の自前ランナー）
./scripts/build.sh          # テスト→ユニバーサルビルド→署名→公証→配布zip
open build/OnomatopeCursor.app
```

構成（4ターゲット・関心の分離）:

- **`Sources/OnomatopeCore/`** — 特徴量トラッカー・分類器・**形態生成器**（`OnomatopeMorphology.swift`）・研究ログ・語彙ストア（AppKit非依存＝テスト対象）。分類閾値は `classifyMotion()`、語形の揺らぎは形態生成器に集約
- **`Sources/OnomatopeCursor/`** — メニューバーアプリ（ボイル描画・エフェクト・センサー群・UI）
- **`Sources/OnomatopeTests/`** — テストランナー（合成軌跡による分類・回帰・イベント・ログ・言語パック検証）
- **`Sources/OnomatopeSynth/`** — ML蒸留用の合成軌跡データ生成（`swift run onomatope-synth ml/logs-synth 30`）

ツール類:

```bash
python3 ml/visualize_log.py               # 自分の研究ログを6パネルのダッシュボードに
python3 ml/sweep_early.py                 # 先読みモデルの精度×レイテンシー実測カーブ
./tools/auto_experiment.sh                # オート被験者実験（合成カーソルが全パターン実行→自動レポート）
python3 tools/make_key_visual.py          # キービジュアル再生成（他のtools/make_*.pyで全図版を再現可能）
```

署名はDeveloper ID証明書＋`notarytool`プロファイルがあれば自動で公証まで、無ければad-hocにフォールバックします。
