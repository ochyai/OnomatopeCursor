# プライバシーポリシー / Privacy Policy — OnomatopeCursor

*最終更新 / Last updated: 2026-07-31*

OnomatopeCursorは筑波大学デジタルネイチャー研究室の研究プロジェクトです（Yoichi Ochiai / Miki Okamura）。
OnomatopeCursor is a research project of the Digital Nature Group, University of Tsukuba.

## 既定では何も収集しません / Nothing is collected by default

- 初期状態では、ネットワーク通信・記録は一切行いません。
- By default the app performs no network communication and records nothing.

## オプトインのデータ提供 / Opt-in data contribution

「データ提供に協力」をONにした場合のみ、以下が匿名IDとともに研究サーバー（insert-only）へ送信されます:
Only if you explicitly enable "Contribute data", the following is sent with a random anonymous ID to an insert-only research server:

- カーソルの運動特徴量（速度・方向転換など） / cursor kinematic features (speed, reversals, ...)
- 表示されたオノマトペ / the displayed onomatopoeia words
- アプリ内フィードバック（「チガウチガウ」・2択クイズ・アンケート回答） / in-app feedback

送信内容は有効化のたびにダイアログで明示され、いつでもOFFにできます。
The exact content is shown each time you enable it, and you can turn it off at any time.

## 収集しないもの / What we never collect

- 画面の内容・スクリーンショット / screen contents
- キー入力の内容（押した「事実」のみ使用、どのキーかは見ません） / typed characters (only the fact of a keypress)
- クリック先・URL・文書内容 / click targets, URLs, document contents
- 氏名・メールアドレス等の個人情報 / personal information

## データの利用 / Use of data

収集データは本研究（動きの言語的ミラーリングと自己主体感）の分析・語彙とレンダリングの改善・学術発表（統計量のみ）に使用します。
Data is used for this research project's analysis, improving the vocabulary/rendering, and academic publication (aggregate statistics only).
